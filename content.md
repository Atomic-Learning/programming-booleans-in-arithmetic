In many, but far from all, programming languages, the boolean values `true` and `false` are treated as the numbers 1 and 0 respectively when used in arithmetic expressions. This means that you can use boolean values in calculations, and they will behave like numbers.

For example, in a language that treats `true` as 1 and `false` as 0, the following expressions would evaluate as follows:

```
true + true  // evaluates to 2
true + false // evaluates to 1
false + false // evaluates to 0
```
